Implemented
QuarryPluginPolish integrates Pixel Play's projection/arrow-angle core with the
existing current objective. A single reusable marker shows destination and metres
only when the goal is off-screen, reachable and farther than two metres. It hides
for mining, camera guidance, blocked input, pause, on-screen targets and completion.
Its safe-area region avoids the existing joystick, action button and task HUD.
Three non-raycast graphics (backplate, arrow and caption), one small nested canvas,
no GraphicRaycaster, no additional rendering camera, no world meshes or particles.

UI Shiny gives the cash header a short sweep after cash increases and the cart
button one sweep when unlocked. Events earned during blocked input defer until
control returns. Restored state never replays a celebration; spending does not
celebrate. Cash sweeps have a three-second cooldown; no loops. Both components are
reused, disable after the effect and restore the original default UI material.
No shader or material work is performed per-frame while those effects are idle.

Atlas compatibility
Screenshot review caught cyan atlas rectangles from the bundled legacy UIShiny's
packed UV0 mapping. The final project-local QuarryUIShiny adapter preserves UV0,
uses normalized UV1 parameters and retains the plugin's effect player/parameter
texture/material-cache system. Its small single-pass shader is explicitly referenced
by scene assets for builds. Third-party plugin source was not modified. Both active
targets share one cached effect material. Existing UI canvas TexCoord1 is enabled
for the adapter. Shader fallback: unsupported shader means no sweep.
