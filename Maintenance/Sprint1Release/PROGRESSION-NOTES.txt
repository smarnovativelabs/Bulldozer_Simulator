SPRINT 1 PROGRESSION

Excavation 1: deliver 12 refined stones for $40. Completion grants free permanent wheelbarrow ownership (no second charge or refund if already owned).
Excavation 2: collect 12 raw pickups while using the wheelbarrow for $60. Existing rich-vein modifier remains.
Excavation 3: deliver 12 copper ingots for $90. Completion permanently unlocks Copper Ridge.
Excavation 4 onward: Copper Ridge opens, adding six copper deposits (84 total rocks rather than 78). Contracts rotate delivery / copper / tough rocks, paying $100. Existing shift modifiers, upgrades and optional tasks continue.
Contracts are optional and cannot block completing the excavation. Rewards are automatically included in the same durable gameplay transaction as the action that completes them.
The next-round preview shows destination/milestone and the next contract. Ridge deposits become active on excavation 4, never halfway through excavation 3.

SAVE CONTRACT
Schema 8 adds contract ID/progress/claimed and permanent area ownership. Stable numeric contract IDs and existing rock IDs must not be renumbered.
Version 7 and earlier saves retain existing progression through the migration chain. Existing in-progress saves receive an achievable 'finish this excavation' contract; already-completed saves do not receive retroactive contract cash. Earned milestones are restored from round progress.
New contracts reset only when a new excavation is durably committed. Upgrades, wallet, purchases and ownership persist.
Future releases must preserve app data identity and add migrations; this does not guarantee arbitrary later schema changes without testing.

IMPLEMENTATION
Six deposits reuse existing meshes/materials and crack visuals. Five perimeter sections are static-batched; one gate enables/disables once on scene start. No added particles, lights, Update loops or runtime navigation baking for the area.
Navigation is baked in CopperRidgeNavigation.asset. The gate carves the baked route while closed. Guidance ignores unavailable rocks.
HUD uses existing fonts/card assets plus two replaceable text labels; no final artwork added.
Fixed a fast-next-round race: wait for the previous loading reveal to release SceneLoadingService before starting the next load.
