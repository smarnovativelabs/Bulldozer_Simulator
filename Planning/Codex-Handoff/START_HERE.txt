BEFORE IMPLEMENTATION
The repository review applies to commit:
b57be43724b8a2988bb7fdd024a4dfdb907d678e
That matches the project's HEAD when these files were added. Future changes may
make some findings stale; inspect the actual project before acting.

Planning/Project-Exploration.md and the research pack contain different proposed
first sprints. The repository proposes bridge rebuilding, two materials, 15-unit
cargo and optional upgrades. The research pack proposes a delivery beacon, one
material, 8-unit cargo and one required drill upgrade. Full-cargo rules differ too.
Use the latest human-approved direction and one authoritative spec before coding.
Do not silently combine the two proposals. The existing planning file is preserved.

The ready-to-paste implementation prompt is:

Resolve the specification differences above before using it as an implementation
contract. Merely reading these files is not a request to implement either proposal.

RESEARCH LIMITS

reviewed without a Unity import, compilation or playtest. Reference screenshots
are research material; do not copy them into game Assets or builds. The new game
should use original or properly licensed content.
